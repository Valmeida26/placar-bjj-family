🥋 Placar BJJ Family



Sistema de placar digital desenvolvido para competições internas e externas da BJJ Family – Escola de Jiu-Jitsu.



📋 Sobre o Projeto



O Placar BJJ Family é uma aplicação web leve e responsiva projetada para exibição em televisores, projetores ou monitores durante eventos de Jiu-Jitsu.



O sistema permite controle em tempo real da pontuação dos atletas e do tempo de luta, oferecendo uma interface simples, visual e intuitiva.



Este projeto foi adaptado e reestruturado com base no repositório original disponível em:

👉 https://github.com/andrepfdev/placar-bjjcompetidor



🚀 Funcionalidades



✅ Controle de pontuação para dois atletas



✅ Controle de vantagens e faltas



✅ Cronômetro com opções de:



2 minutos



3 minutos



5 minutos



✅ Pausar / Retomar cronômetro



✅ Ajuste manual de tempo



✅ Alerta sonoro pra quando acaba o tempo



✅ Modo tela cheia



✅ Reiniciar placar



✅ Identificação visual da escola (logo personalizada)



✅ Código-fonte disponível para download

📦 Instalação e Uso

1️⃣ Download



Baixe o projeto em formato .zip ou clone o repositório:



git clone https://github.com/Valmeida26/placar-bjj-family.git

2️⃣ Executar



Extraia os arquivos (se baixado em .zip)



Acesse a pasta do projeto:



placar-bjj-family



Abra o arquivo index.html no navegador de sua preferência.



💡 Sugestão:

Utilize a função Tela Duplicada do Windows para exibir o placar em um segundo monitor ou TV durante os eventos.
